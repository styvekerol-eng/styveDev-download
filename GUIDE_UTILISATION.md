# ✨ StyveDev Download Pro — Guide d'utilisation

Bienvenue dans **StyveDev Download Pro v4.0** !
Vous disposez désormais de la version **Application Windows (.EXE)** ET de la version **PWA Multiplateformes (Android & iOS)**.

---

## 💻 1. Sur votre PC Windows : Deux façons de l'utiliser

### Option A : L'application Windows autonome (.EXE) — Recommandé
👉 Double-cliquez directement sur :
**`StyveDev_Download_Pro.exe`**

- Il s'agit de votre application **`download.py`** compilée en un vrai logiciel Windows natif.
- Elle possède son icône personnalisée, fonctionne sans invite de commande et intègre tout (Python, CustomTkinter, yt-dlp, FFmpeg).
- Vous pouvez créer un raccourci de ce fichier sur votre **Bureau Windows** ou l'envoyer sur un autre PC.

### Option B : Le mode développement Python
👉 Double-cliquez sur **`lancer_app.bat`** pour exécuter directement le code source `download.py`.

---

## 📱 2. Sur Mobile (Android & iPhone / iPad)

Pour utiliser et installer l'application sur votre smartphone ou tablette :

1. Sur votre PC, lancez **`start.bat`** pour démarrer le serveur local.
2. Connectez votre téléphone au **même réseau Wi-Fi** que votre PC.
3. Ouvrez Chrome (sur Android) ou Safari (sur iPhone) et entrez :
   ```
   http://192.168.1.178:8765
   ```
4. **Pour l'installer sur votre écran d'accueil :**
   - **Android :** Cliquez sur la bannière **« Installer »** en haut, ou dans le menu des 3 points > *« Ajouter à l'écran d'accueil »*.
   - **iPhone (Safari) :** Appuyez sur le bouton de **Partage** (icône carré avec flèche vers le haut) puis sur **« Sur l'écran d'accueil »**.

---

## 📥 3. Télécharger le .EXE depuis le site Web

Si vous accédez au site web sur un autre ordinateur de votre réseau local, un bouton **« 💻 Télécharger .EXE »** est disponible directement dans l'en-tête du site pour télécharger l'exécutable Windows en 1 clic.

## 🌟 4. Fonctionnalités incluses

- **Taille exacte avant téléchargement :** Chaque format (Meilleure qualité, 1080p, 720p, 480p, 360p, MP3 320 kbps, M4A) affiche la taille exacte calculée avant que vous ne cliquiez sur Télécharger.
- **Sécurité Anti-Playlist :** L'option *« Vidéo seule »* est activée par défaut pour éviter de télécharger des playlists entières par erreur.
- **Support 1500+ sites :** YouTube, Facebook, Instagram, TikTok, Twitter/X, Twitch, Reddit, Vimeo, Dailymotion, etc.
