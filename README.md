# ✨ StyveDev Download Pro — PWA & Cloud

Application universelle et moderne de téléchargement multi-plateformes haute vitesse avec calcul de la taille exacte avant téléchargement.

## 🚀 Fonctionnalités
- 🌐 **Multi-plateformes** : YouTube, Facebook, Instagram, TikTok, Twitter/X, Twitch, Reddit, Vimeo, Dailymotion et +1500 sites.
- 📦 **Taille exacte** : Calcul des flux et estimation précise de la taille du fichier avant de lancer le téléchargement.
- 🌍 **Multi-langues** : Support natif du Français (FR), Anglais (EN), Espagnol (ES), Allemand (DE), Portugais (PT) et Arabe (AR avec support RTL).
- 🎨 **Design Moderne** : Thèmes Sombre / Clair / Système, animations fluides, vraies icônes vectorielles SVG.
- 📱 **Progressive Web App (PWA)** : Installable sur PC, Android et iOS.
- ⏹ **Contrôle total** : Bouton d'arrêt d'urgence instantané du téléchargement.

## 🛠️ Déploiement Cloud Gratuit (Render.com)
1. Créez un compte gratuit sur [Render.com](https://render.com).
2. Cliquez sur **New +** > **Web Service**.
3. Connectez votre dépôt GitHub ou utilisez le mode **Docker**.
4. Render détectera automatiquement le fichier `Dockerfile` ou `render.yaml`.
5. Votre application sera déployée et accessible via une URL publique sécurisée `https://...` !

## 💻 Lancement Local
```bash
pip install -r requirements.txt
python server.py
```
Accès dans le navigateur : `http://127.0.0.1:8765`
